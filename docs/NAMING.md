# Naming conventions

- F3 Mapper model: `UsersM`, `CoursesM`, `ThemeDefinitionsM`
- Controller: `AdminController`, `LearningController`
- Service: `PlatformAdministrationService`, `LearningService`
- Repository: `AdministrationRepository`, `CourseRepository`
- Value or support classes use descriptive names without artificial suffixes.

`M` is intentionally retained as the short suffix for F3 Mapper models. Other descriptive suffixes are written in full.
