## The command sequence

### 1. Allow Git to use a directory on the H: drive

The H: drive does not record file ownership, so Git refuses to operate until the path is trusted.

```bash
git config --global --add safe.directory H:/00_Catto_Learning/WORKAREA/cattolms-v0.5.7.4
```

### 2. Create the repository with `main` as the initial branch

```bash
cd H:/00_Catto_Learning/WORKAREA/cattolms-v0.5.7.4
git init -b main
```

### 3. Point it at GitHub

```bash
git remote add origin https://github.com/rrcatto/cattolms.git
```

### 4. Fetch the existing 0.5.4 history

```bash
git fetch origin main
```

### 5. Attach that history without disturbing the working tree

This is the step that preserves the 0.5.4 commit. `--mixed` moves the branch pointer and loads the 0.5.4 file
list into the index, but **does not touch any file on disk** — the 0.5.7.4 files stay exactly as they are.

```bash
git reset --mixed FETCH_HEAD
```

Git now understands the 0.5.4 tree as "what was there before", so the next commit records a true
0.5.4 → 0.5.7.4 difference including files that were removed.

> Avoid `git reset --hard` here. It would overwrite the 0.5.7.4 working tree with 0.5.4 files.

### 6. Stage everything, honouring `.gitignore`

```bash
git add -A
```

### 7. Verify before committing

```bash
git status
git diff --cached --stat HEAD                                  # scale of the change
git diff --cached --name-status HEAD | grep '^D'               # what is being removed
git status --porcelain --ignored=matching | grep '^!!'         # confirm exclusions are correct
```

### 9. Push to the remote main branch

```bash

```

## Consequence of excluding `/themes/`

`themes/default` (17 files) existed in the 0.5.4 commit and is **deleted** by this release. Nothing replaces
it, because `/themes/` is now ignored.

This is deliberate, but note that `ThemeManager::bundledFactoryResetRoot()` resolves the bundled recovery
theme at `<codeRoot>/themes/factory-reset`, and both `tools/check-runtime-hazards.php` and
`tools/validate-ui-contracts.php` read that same path. A fresh clone of this repository therefore contains no
bundled theme. Decide separately whether Factory Reset should ship in the repository or be delivered only by
the installer.

## Rollback

Before pushing — undo the commit, keep all files:

```bash
git reset --soft HEAD~1
```

After pushing — revert the release commit as a new commit (safe, preserves history):

```bash

git push origin main
```

Discard the local repository entirely without touching the project files:

