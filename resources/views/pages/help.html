How Catto Learning works

Open a topic below for a concise explanation of the platform workflow or control.

Getting around

My Learning is your learner library. Profile contains personal particulars and account details. Platform administrators use Administration for the dashboard, courses, people, companies, enrolments, credits, activity, reports, themes and settings.

People and roles

Platform Administrators can open any person and edit their complete profile, company and roles. Course Owners control owned courses; Course Editors edit assigned courses; Learners take courses.

Companies

The permanent System Company represents the organisation hosting the LMS. People who do not belong to a third-party company belong to it. Its default domain comes from APP_DOMAIN.

Course reset and deletion

Reset removes course content and learner test data but keeps the course shell for re-import. Delete permanently scrubs the course and associated learner access, progress, results and course-specific data.

Theme Manager and Theme SDK

Themes are externally authored Theme Package 3.0 ZIP releases described by theme.json. Administration can validate and install a release, preview it, activate it, or uninstall it when inactive. Theme source is not edited or exported by the LMS. Child themes are anchored to one exact standalone parent name + version and supply at least their own theme.css.

Developer documentation is supplied in docs/THEME-SDK.md, including the required navigation and component styling contracts.

Theme development

Create or change themes outside Catto Learning using the Theme SDK. A minimal standalone theme needs a manifest, base.html and public/css/theme.css. A full theme can add page-family wrappers, partials, browser JavaScript, assets and declared HTTPS CDN resources.

Browser JavaScript is presentation-only. Themes never execute PHP or replace LMS security and business logic.
