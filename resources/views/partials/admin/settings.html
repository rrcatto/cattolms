Configuration model

The LMS deliberately separates deployment secrets from administrator-managed runtime settings.

Database-over-.env settings

Platform name and outgoing mail may be changed here. Removing an override returns that setting to its .env default.

Infrastructure remains in .env

Database credentials, APP_KEY, application URL/domain, cookie/security settings and filesystem/deployment configuration are not exposed in the web UI.
