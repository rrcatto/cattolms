Install immutable Theme Package 3.0 ZIP releases, preview them, switch the live theme, or uninstall an inactive theme.

i
The LMS does not edit or export themes.
Theme authors maintain source externally and publish each update as a new version. Installed name + version releases remain side-by-side. Factory Reset is the default theme, not a fallback for unrelated themes.

Installed themes

The filesystem is authoritative. PostgreSQL keeps a rebuildable metadata registry so parent/child relationships and theme status can be presented clearly.
