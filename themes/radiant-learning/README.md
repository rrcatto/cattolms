# Radiant Learning 3.2.0

Recovered from the Catto Learning v0.5.5 `radiant-learning.seed.json` (Radiant Learning 3.1.0) and adapted to Theme Package 3.0.

The original visual CSS is retained. Obsolete Theme Studio/database behaviour and platform-business JavaScript were not carried into the recovered theme. The package uses Catto Learning core page bodies and the Theme Template API 1.0.

Palette switcher: Ocean & Sun, Woodland, Tranquil.
