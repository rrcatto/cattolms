How Catto Learning works

Short explanations of the workflows and controls used throughout the platform.

Getting around

My Learning is your learner library. Profile contains personal particulars and account details. Platform administrators use the Administration menu for the administrative dashboard, courses, people, companies, enrolments, activity, reports and settings.

People & roles

Platform Administrators can open any person and edit their complete profile, company and roles. Course Owners control owned courses; Course Editors edit assigned courses; Learners take courses.

Companies

The permanent System Company represents the organisation hosting the LMS. People who do not belong to a third-party company belong to it. Its default domain comes from APP_DOMAIN.

Course reset & deletion

Reset removes course content and learner test data but keeps the course shell for re-import. Delete permanently scrubs the course and all associated learner access, progress, results and course-specific data.

Theme Studio & Theme SDK

Themes are portable ZIP packages described by theme.json. Import validates and inspects a package before creating a draft. Save draft never changes the live site; Activate / Apply draft publishes the selected snapshot. Export rebuilds a portable ZIP. Developer documentation is supplied in docs/THEME-PACKAGE-SPECIFICATION.md and docs/THEME-SDK.md.

Theme editing

Theme Studio provides palettes and semantic colour roles, typography, navigation and context-bar layout, content/card/footer presentation, front-page hero controls, desktop/tablet/mobile preview, binary asset management and optional raw HTML/F3/CSS/JavaScript editing. Advanced Custom CSS loads last and overrides the visual layer. Ordinary theme packages never execute PHP.
