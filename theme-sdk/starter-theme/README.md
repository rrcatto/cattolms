# Catto Learning starter theme

This directory is the scaffold used by the Catto Learning Theme SDK generator. Edit `theme.json`, HTML/F3 templates, CSS and JavaScript, then ZIP the directory contents so `theme.json` is at the archive root.

Normal themes do **not** execute PHP. See `docs/THEME-PACKAGE-SPECIFICATION.md` and `docs/THEME-SDK.md` in the LMS source tree.
